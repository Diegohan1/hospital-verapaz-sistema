# Manual de usuario — Sistema de Expediente Clínico y Administrativo

**Hospital de Especialidades Verapaz — Cobán, Alta Verapaz**

Este manual está diseñado para cualquier usuario del sistema, sin conocimientos técnicos. Se explica paso a paso cómo usar cada módulo con imágenes de ejemplo.

## 1. Acceso al sistema

### 1.1 Pantalla de inicio de sesión

Para ingresar al sistema debe escribir su correo electrónico y contraseña proporcionados por el Administrador.

![Pantalla de inicio de sesión](./capturas_usuario/01-login-pantalla.png)

1. Escriba su **correo electrónico**.
2. Escriba su **contraseña**.
3. Presione el botón **Ingresar**.

### 1.2 Menú principal

Al ingresar correctamente, aparecerá el menú lateral con los módulos a los que tiene acceso según su rol.

![Menú principal del sistema](./capturas_usuario/01-login-ok-menu.png)

## 2. Registro y Admisión

Este módulo permite registrar nuevos pacientes, buscar pacientes ya registrados y actualizar información.

### 2.1 Lista de pacientes registrados

Al entrar a **Registro y Admisión**, se muestra la lista de todos los pacientes registrados con su nombre, historia clínica, DPI y otros datos.

![Lista de pacientes registrados](./capturas_usuario/02-registro-lista.png)

Para buscar un paciente, use el campo de búsqueda escribiendo el nombre, DPI o número de historia clínica. También puede usar la «X» para limpiar la búsqueda.

### 2.2 Registrar un paciente nuevo

1. Presione el botón **+ Paciente nuevo**.
2. Llene los datos obligatorios del formulario.
3. Presione **Guardar paciente**.

![Formulario para registrar paciente nuevo](./capturas_usuario/03-registro-nuevo-paciente.png)

### 2.3 Datos opcionales

Si necesita agregar más información, presione **Mostrar datos opcionales** para desplegar campos adicionales.

![Datos opcionales del paciente](./capturas_usuario/04-registro-datos-opcionales.png)

## 3. Expediente Clínico

Permite consultar el historial de ingresos del paciente y ver o registrar diagnósticos por cada ingreso.

### 3.1 Buscar paciente en expediente

1. Seleccione **Expediente Clínico** en el menú.
2. Busque el paciente por nombre, DPI o historia clínica.
3. Seleccione el paciente para ver su expediente.

![Búsqueda de paciente en Expediente Clínico](./capturas_usuario/05-expediente-busqueda.png)

![Paciente seleccionado en Expediente Clínico](./capturas_usuario/06-expediente-buscar.png)

![Documentos del Paciente](./capturas_usuario/07-documentos-paciente.png)

Permite registrar y dar seguimiento a los gastos del hospital por categoría.

![Módulo de Gastos del Hospital](./capturas_usuario/11-gastos.png)

Permite administrar inventario, registrar entradas/salidas de medicamentos y realizar ventas directas.

![Módulo de Farmacia - Inventario](./capturas_usuario/12-farmacia.png)

## 10. Seguridad y Roles

Solo el Administrador puede acceder a este módulo. Permite crear usuarios, asignar roles y generar códigos para acceder a diagnósticos.

![Módulo de Seguridad y Roles](./capturas_usuario/14-seguridad-usuarios.png)

## 11. Reportes

Permite consultar reportes administrativos, financieros y auditoría de accesos.

![Módulo de Reportes](./capturas_usuario/15-reportes.png)

## 12. Recomendaciones de uso

- Cierre siempre su sesión al terminar de usar el sistema en una computadora compartida.
- Revise bien los datos antes de guardar.
- Solo el Administrador puede generar códigos para ver diagnósticos confidenciales.
- Si olvida su contraseña, use la opción «Recuperar contraseña» en la pantalla de inicio.
